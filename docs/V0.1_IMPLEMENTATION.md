# V0.1 实施说明

> 历史验收摘要来自维护者本地记录。文中 `local-acceptance/`、`output/` 和标注产物保留在本地，公开仓库提供源码与合成示例。测试结果按记录日期和所列范围解释，完整 V1 验收仍在进行。


原设计规格保留未修改；此说明只界定本次可运行的 V0.1。

## 版本边界与实现路径

CLI 解析 → 配置合并与 Schema 校验 → EXIF 转正 / RGB / 保持比例缩小 → DepthBackend 真实模型或用户深度 → 归一化 → Motion Manifest → Web Renderer → Project Manifest / Validator。

核心只依赖 Pillow、NumPy、PyYAML、jsonschema；模型后端按需导入 torch / transformers。运行时和 Preset 作为 Python 包数据安装，从任意工作目录可用。Renderer 只消费 Motion Manifest 和其资源，不进行推理或图像分析。

模型准备解析官方 revision 为提交 SHA，只下载必要文件，记录文件 SHA-256 和许可。推理逐项校验本地文件，并使用 local_files_only=True。默认 CPU，CUDA 不可用时报错。归一化针对每张图，近白远黑，范围 [0,1]，非米制或绝对距离。常量深度明确 warning，不宣称局部深度视差成功。

## 单位与公式

短边 S = min(width,height)。最大单轴幅度 A = S × fraction；fraction 上限 0.01。Motion 中 amplitude_px / overscan_px 都以导出画布像素计，response_seconds 为指数响应时间常数。

Web shader 将鼠标标准化到 [-1,1]²，指数平滑系数 `1-exp(-dt/response_seconds)`。深度权重 `w=0.2+0.8*d`，UV 位移 `-mouse*A*w/imageSize`。白色最大、黑色为其 20%；反转鼠标方向反转位移，不只是整个图片平移。

安全边缘：A>0 时每侧留 A+2 画布像素，最后 clamp 到半纹素边界；A=0 不留额外安全裁切，鼠标变化不改变画面。窗口比例不同时以 cover 显示，安全取样可能产生少量放大，不是背景补洞。

模型 RGB 输出只做标准转正、透明合成黑底和 Lanczos 缩放，不生成重绘。深度存 PNG L 8 位，内部预测 float32，PNG 量化误差最多约 1/510。用户深度与原图必须同尺寸；方向只接受近白，不猜测反向。

## 输出、安全与验证

原子 mkdir 分配版本，进程/线程并发不会拿到同一目录。推理失败不生成假资源。版本创建后的失败保留 generation-error.json。覆盖须显式指定管理版本，拒绝无关文件；以旁路 staging 生成并通过结构验收，原目录改名备份后切换，失败回滚。备份不自动删除。

Project Manifest 记录输入文件名和原哈希，不泄露绝对路径，记录资源哈希、模型 SHA、许可、依赖和运行时版本。HTML 内嵌图片、深度和 Motion，外部文件仅为本地 CSS/JS。修改 motion.json 后应重新导出 HTML，不支持直接手改同步或标注编辑器。

验收分层：结构 / 自动浏览器 / 实际视觉。报告四态，后续功能列为 not_applicable。自动浏览器直接打开 file://，检查 WebGL、帧变化、四角 alpha、减少动态、尺寸改变、静态降级、外部请求和脚本错误；另用合成图测近远位移大小及方向、零强度不动。透明检查不是所有视觉缺陷的证明，仍需观察画面。

用户照片仅本机推理验收，不进入公共示例。私人产物和权重均不纳入仓库。SKILL 不复制 renderer，不自动下载、发布或改动用户其他环境。

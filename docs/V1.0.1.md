# 1.0.1 植物摆动与柔边暖尘

用户反馈README湖景的前景花草静止，人物暖尘较淡。本修正版为Web提供可与水波同时运行的局部植物摆动，并给暖尘增加可选柔边。原生支持范围继续由native-plan明确记录。

## 植物区域

```yaml
effects:
  - type: foliage_sway
    region: other
    amplitude_px: 4
    intensity: 0.9
    period_seconds: 2.6666666667
```

需非空、明确确认的other植物权重区域。蒙版灰度控制运动强度，可在数据准备阶段为根部设置较低权重；protected区域抑制形变。实际单轴位移上界由amplitude_px × intensity确定，最多4画布像素且不超过短边1%，计入边缘留量。植物与水波分别采样同一纹理的不同通道，保持WebGL八个纹理采样器预算。

关闭effects、零强度和减少动态偏好均停止植物摆动。该效果独立于人物hair/cloth，不借用人物类别。原生映射仍使用已有显式native_sway能力；foliage_sway本身在native-plan中列为Web范围。

## 暖尘

```yaml
effects:
  - type: dust
    count: 90
    intensity: 0.8
    size_px: 5
    softness: 0.8
    exclude_person: true
```

softness为可选Web字段，范围0–1。显式启用后使用柔边径向粒子；旧配置未提供该字段时保留原有呈现。原生采用自身径向粒子材质，显式softness会在native-plan说明Web与宿主差异。README参数参照此前原生暖尘的可见度调整，位置和随机过程按各目标解释。

## 兼容与验证

旧版本和1.0.0输出继续接受校验。组合纹理从原始区域重新派生并校验；即使重新计算外层文件哈希，错误的植物/水面通道仍会被拒绝。新增真实合成浏览器回归覆盖独立植物、水波组合、保护区、关闭/零强度/减少动态，以及暖尘柔边和人物排除。

2026-11-17安装包完整回归225项通过、311.85秒，其中本次新增专项4项通过。实际湖景隔离检查确认植物、水波、云雾分别时变，8504个石头保护像素保持不变。实际人物背景暖尘覆盖与不透明度较旧版提高，21353个面部检查像素的粒子alpha保持0。这些技术结果按本次样例解释，原生效果随机过程仍遵循宿主实现。

## 已实现闭环

`static2live IMAGE` → 共享prepare_assets → 当前模式的真实分析/导入区域 → 保守保护策略 → 推荐Preset/局部运动 → Motion Manifest → 现有Web/原生Adapter → Validator → Project Manifest。

新增`static2live analyze --input IMAGE ...`只输出JSON分析与建议，不分配版本、不生成壁纸、不记录运行通过。与generate共用同一个分析器，单次生成不会为了推荐重复推理。默认auto_plan:true，可--no-auto-plan关闭；`analyze --no-parallax`可完全无模型。

### 推荐证据

- 从规范RGB计算哈希、尺寸和最多512长边采样的色彩/亮度统计，统计只用于配色，不冒充人物/水面/天气识别。
- 语义证据只能来自当前Smart真实标签、人物解析或显式导入的区域。Lite不调用分割/人物模型；视差仍须真实深度或用户深度，无模型使用需明确--no-parallax。
- 已知人物选portrait_subtle；有person区域且测得暖调时选warm_portrait。已知sky/water/cloud可选landscape_soft。不确定场景选general_balanced并说明语义缺失，不能凭颜色造天空或判断雨雪。
- 有hair/cloth与非空protected时，使用同一build_sway_weight检查是否有真实可动像素，再建议轻微运动；不为了打开动画而缩小保护区。算法1.0的hair建议最多1.5画布像素，修订1.1最多2.5，两者都不超过短边0.5%；cloth最多0.35且不超过0.2%，原有V0.4总上限仍适用。修订原因与旧工程兼容见末节。
- 有明确非空water且覆盖超过2%时建议低强度局部water_ripple。自动规划不擅自开启音乐、不根据图片想象雨雪；其它风格由skill理解用户请求并设置已有Preset/参数。

补齐原规格推荐名称anime_chill、snow_forest、cyberpunk，并打包真实配置。anime_chill组合低尘/局部glow/cloud drift（缺区域按原V0.2规则关闭并warning）；snow_forest组合雪/轻雾；cyberpunk组合雨和V0.6局部neon_pulse（包含有界红蓝偏移）。后者缺非空glow蒙版直接拒绝，不把整图当霓虹灯。它们不是图像重画或动漫/天气分类器；原规格推荐效果中的自动树木识别、Web植物摇摆、独立Light Ray等仍未实现，不声称与所有参考效果完全等同。

### 保护与优先级

已有protected（包括显式空蒙版）不替换。缺失时优先从face/hands构造保护；只有person时保守保护整个人物。填充封闭轮廓孔洞并外扩4画布像素；明确记录source:rule、来源区域和自动安全策略，不宣称用户视觉确认或独立人脸识别。整个人物保护可能使发梢无法动，此时报告原因，不虚构细发丝。

保护蒙版即使没有sway也约束Web及原生深度响应。粒子排除人物时还扣除protected，避免语义孔洞让粒子穿过五官；原始标签和原人物RGB不改写。原生遮挡覆盖板使用person/protected的并集，结构校验复核Alpha。

存在hands却没有face时不能只保护手而遗漏已知person，仍使用整个人物保守保护。原生覆盖板的RGB也与规范原图逐像素比较，不只校验底图，避免粒子遮挡层意外替换人物颜色。

优先级：CLI > 用户YAML > 所选Preset > 自动建议 > 默认值。显式Preset保留，显式effects:[]、enabled:false和0保留。推荐不得改变模式、设备、尺寸、视差开关或额外触发模型下载；若未来Preset试图改变这些分析控制，明确拒绝而不是在不同画布上继续。

### 可检查与可复现

analysis.json.planning记录算法版本、特征、推荐依据、未满足条件、建议与最终选择。manifest.planner记录版本与启用状态。config.yaml是最终有效配置，Renderer不再分析图片。

Validator从已保存的规范RGB及源蒙版重新计算计划，校验保守保护推导、推荐与选中Preset、配置与Motion、资源与哈希。重新计算文件哈希不能掩盖伪造推荐或错误保护。它不验证用户审美，也不能证明模型类别正确；视觉继续not_tested。

配色统计的跨NumPy版本数值舍入仅容许绝对误差1e-12，其他规划字段、RGB/资源哈希、蒙版、动作参数与Preset选择仍精确比较。重生成时Pillow版本不同可能产生不同的规范缩放RGB，依赖版本已记录；验证已有产物从其已保存PNG复算，不重新缩放用户原图，也不放宽像素哈希。

## 使用

```powershell
# 默认Lite，真实深度需先显式准备。自动规划不自动下载。
static2live photo.jpg --model-cache models --output output
# 完全无模型：不冒充自动语义识别
static2live analyze --input photo.jpg --no-parallax
static2live photo.jpg --no-parallax --regions annotations.json --output output
# 已授权准备的本地模型：真实语义+人物解析→自动推荐与微摆
static2live photo.jpg --mode smart --human-parsing --model-cache models --output output
# 精确沿用用户选择，不自动规划
static2live photo.jpg --config precise.yaml --no-auto-plan --output output
```

所有生成仍分配新版本，原图及旧输出保留。Smart缺模型明确拒绝，不回退假深度/假分割。--target wallpaper-engine沿用同一Motion和已有降级/unsupported记录，不承诺原生覆盖所有Web能力。

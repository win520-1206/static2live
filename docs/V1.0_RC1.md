# Static2Live 1.0.0rc1

本候选版已完成未导入人工区域的Smart样例Web技术与用户视觉确认，整体报告passed。用户确认整体自然、人物连续且脸稳定，默认衣料独立可辨性未单独确认。项目随后整理为[1.0.0本地交付版](V1.0_RELEASE.md)，下文保留候选版当时的过程和范围。

2026-11-17整理的本地候选版，面向原规格第39节的自动分析、推荐、Motion Manifest、双目标输出和验证闭环。

## 使用入口

从项目目录安装源码或本地wheel，然后在任意工作目录调用CLI。

```powershell
python -m pip install .
static2live --version
static2live photo.jpg --mode lite --no-parallax --effect dust
static2live photo.jpg --mode smart --human-parsing --model-cache models
static2live photo.jpg --target wallpaper-engine --mode smart --human-parsing --model-cache models
```

Smart及深度推理需已有本地模型，首次准备、许可和国内镜像步骤见[README](../README.md)。Lite导入用户蒙版可使用局部运动，完全无模型时显式关闭视差。CLI优先级和单位沿用现有契约。

## 交付能力

- Python包与CLI负责分析、模型来源记录、确定性规划、版本化输出和验证。
- Motion Manifest描述画布、区域、保护、视差、局部运动、粒子、音频及Shader。Planner版本1.2，Motion版本继续采用已有0.2/0.4/0.6契约。
- Web以离线嵌入资源运行WebGL局部UV动画，提供平滑鼠标响应、采样边缘留量、减少动态偏好及静态降级提示。
- Lite使用人工区域或已确认的规则候选，Smart使用真实本地语义和人物模型，预测结果可在离线编辑器修改后重新生成。
- 原生Adapter读取本机合法模板并编译真实纹理，输出完整依赖、属性和明确的未映射项。
- 薄skill负责自然语言到参数、CLI调用和验收报告，运行公式由核心包统一实现。

## 能力边界

- 语义模型类别有限，自动推荐受现有区域证据约束，人物保护需结合预测和实际画面核对。
- tree sway、独立light ray等原规格推荐风格仍是后续扩展，背景补全保留为可选路线。
- 原生性能配置和虚拟裁切由Wallpaper Engine管理，具体unsupported见输出native-plan。Web性能预算已有软件渲染测试，精确原生硬件FPS与显存尚无测量。
- 多屏支持Web归一化viewport及原生逐屏覆盖裁切，人物取景可由用户调整。连续拼接与多实例时钟同步尚未验收。
- 自动语言解析由宿主Agent和skill执行，CLI接收结构化参数。独立Agent行为评估尚未执行。

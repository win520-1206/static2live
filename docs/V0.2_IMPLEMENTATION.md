# V0.2 实施说明

核心为 Pillow、NumPy、YAML、Schema；depth/smart 可选依赖 PyTorch、Transformers、Hub。Lite 不导入 ML，关闭视差时无模型或深度资产。Smart local_files_only 推理 SegFormer B0 ADE，按真实类别表归并人物/天空/水面，保存 labels；分批双线性插值 logits 再 argmax，避免全150类大尺寸内存。

regions.py 统一 EXIF 和画布，校验输入哈希、比例、尺寸、确认状态与来源。离线绘制页面归一化坐标映射，画笔/擦除/导入/保存，规则候选必须确认。Smart 人工同类区域覆盖预测，保存来源。软蒙版双线性，标签图最近邻。

Motion 0.2 增加 mode、seed、区域与效果；Renderer 只消费 Manifest。WebGL 基图深度局部 UV 与确认云蒙版有限周期 UV 位移；Canvas2D 雨雪尘雾与区域亮度脉冲。固定种子、每类最多256粒子、均匀全画布起点、区域裁剪及保守人物排除；不补全背景，不等于动态精细分层或五官保护。

HTML 内嵌纹理和配置，无 file:// fetch；减少动态停止全部动画；WebGL 失败显示静态并说明。Manifest 记录资源 SHA256、配置、运行时及模型 revision/许可；analysis 记录原图 canonical RGB 哈希。版本分配、并发和覆盖安全沿用 V0.1，兼容旧 Manifest。

Validator 分结构、浏览器、视觉；核验哈希、嵌入数据、配置与 Motion 对应、区域与标签。浏览器测时间差、鼠标、关闭效果、减少动态、缩放、边缘、降级；视觉记录绑定同一 Manifest。

已实现 Lite/Smart、六种效果、基础标注、Preset、CLI、安装包和薄 skill；不含发梢、表情、背景补全、原生 Wallpaper Engine、视频或完整编辑器。官方模型下载已获用户授权，生成/播放离线，照片未上传。国内镜像规则保留官方版本与哈希核验。

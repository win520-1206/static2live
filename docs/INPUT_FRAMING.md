## 坐标与溯源

先EXIF转正，再在源坐标裁切，最后缩放到max_edge。过宽输入水平居中裁切；过高输入按纵向锚定裁切。真实深度模型接收裁切后的规范RGB。外部深度仍要求完整转正后源尺寸，先归一化，再用同一框裁切，不因裁切重定义近远值。完整图区域按源框投影到其蒙版分辨率、裁切后缩放，低分辨率投影有取整误差。

analysis.crop记录源框；assets/regions.json.input_frame记录原尺寸、源框及坐标定义。已经裁切的bundle仅在框完全一致时复用，跨框或回完整原图拒绝，不假装重建已丢失信息。annotate仍使用完整原图；需要变更取景时应从完整原图标注重新生成。Validator独立复算框、画布比例和bundle坐标声明。原图哈希与原输出保持，不覆盖。

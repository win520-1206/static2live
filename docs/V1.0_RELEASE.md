# Static2Live 1.0.0

2026-11-17定稿的本地交付版。项目由Python核心包、CLI、运行时及薄skill组成，按原规格完成图像分析、自动推荐、Motion Manifest、Web/可选原生输出与分级验证闭环。

## 已交付能力

| 范围 | 实现 |
| --- | --- |
| 分析与规划 | 默认自动推荐Preset及有区域证据的局部运动，推荐依据可检查，支持显式关闭 |
| Lite | 人工区域、离线绘制编辑器及规则候选，关闭视差后可完全无模型运行 |
| Smart | 本地深度、语义分割及可选人物解析，模型显式准备、记录revision/许可/哈希 |
| 运动 | 深度视差、发梢/衣料局部UV运动、区域Shader、粒子及保护蒙版 |
| Web | 离线嵌入资源、WebGL、鼠标平滑、性能档、虚拟viewport、可选音频响应 |
| Wallpaper Engine | 本机合法模板与真实纹理编译、完整场景依赖、用户属性及可选音频/Shader映射 |
| CLI与输出 | 版本化独立目录、显式覆盖检查、CLI优先级、Manifest及资源哈希 |
| 验收 | 结构、浏览器、人工视觉、原生及能力分项分别记录，截图证据独立版本化 |
| skill | 自然语言映射、调用现有CLI、读取报告和按实际范围交付 |

包版本为1.0.0。Planner算法保持1.2，Motion契约保持已有0.2/0.4/0.6。Validator继续接受0.1.0、0.2.0、0.3.0及1.0.0rc1项目。

## 安装和调用

使用交付的本地wheel，或从源码目录安装。

```powershell
python -m pip install .
static2live --version
static2live photo.jpg --mode lite --no-parallax --effect dust
static2live photo.jpg --mode smart --human-parsing --model-cache models
static2live photo.jpg --target wallpaper-engine --mode smart --human-parsing --model-cache models
```

Smart及视差需已有相应本地模型。首次准备、可选依赖、模型独立许可及慢速国内镜像步骤见[README](../README.md)，参数映射见[skill工作流](../references/workflow.md)。

## 1.0范围限制

- 人物模型是粗类别解析，预测可能需要人工修正。自动推荐保守，运动幅度可按素材调整。
- 原生性能配置与虚拟裁切交由Wallpaper Engine管理，未映射功能会列入native-plan。精确原生硬件FPS及显存未测量。
- 多屏已有Web归一化viewport和原生逐屏覆盖裁切，连续拼接与多实例时钟同步尚未验收。
- 树木自动识别、独立light ray、精细发丝Alpha Matting和背景补全保留为后续范围。当前未提供表情或视频导出。
- 独立Agent行为评估尚未执行，现有skill证据包括实际主Agent使用、引用检查和已安装CLI配方测试。

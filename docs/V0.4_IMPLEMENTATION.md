# V0.4 人物解析与局部摇摆（开发中）

> 历史验收摘要来自维护者本地记录。文中 `local-acceptance/`、`output/` 和标注产物保留在本地，公开仓库提供源码与合成示例。测试结果按记录日期和所列范围解释，完整 V1 验收仍在进行。


## 侧梢权重修订（2026-10-16，仍待视觉验收）

后续V1样例1.5及2.5像素均收到“发梢看不出来”反馈，旧v005的用户通过不适用于它们。只读对比确认旧版和2.5修正版的权重PNG、编译TEX、Shader与发梢参数完全一致；实际编辑器也显示正确纹理及参数，尚不能证明GPU运动可辨或排除宿主问题。

已确认的影响因素是全头高度线性权重衰减上侧外缘，缩小且裁切的检查视图进一步削弱可辨性。新导出采用tip-edge-v2：顶部20%锚定；20%至55%高度smoothstep渐入，仅头发窄轮廓带，内部不动，保护留量和幅度上限不变。衍生区域记录weight_policy；无字段旧版仍按distal-linear-v1重建校验。衣料算法不改，不缩小保护区、不转为整图晃动。

145项安装包回归通过，包括新侧梢权重/根部/内部/保护区/位移上限测试；真实照片离线CPU重新生成、结构通过。但新权重自然程度、实际可辨性、零强度/开关和长时验证仍未完整通过，不能以此宣布V0.4或V1完成。

## 当前已实现

- HumanParsingBackend 接口及 FASHN 本地后端，继承已验证的本地-only推理与缓存哈希检查。推理不联网、不重绘 RGB；后端返回与图像同尺寸的真实类别标签、类别表及来源记录。
- 显式 `models prepare --kind human-parsing --accept-model-license`，支持既有官方源/国内镜像及官方 revision、哈希校验。此命令只准备权重，不等于完整 V0.4 生成。
- face / hands / hair / cloth / body / person / protected 蒙版构造。保护区合并脸、手、眼镜、首饰和配饰，有限外扩后从头发和衣料提议区域中减去；眼睛通过 face 覆盖，不冒充独立眼睛识别。无人物时返回空蒙版，不虚构人脸。
- 原始标签不修改。类别缺失、未知类别、非整数/空标签、非法外扩、错误缓存身份及哈希失败明确拒绝。
- Pipeline 已接入 `human_parsing`、`hair_sway` 和 `cloth_sway`，自动解析或 Lite 导入同尺寸 hair/cloth/protected 蒙版。缺非空保护区直接报错，不猜测坐标。
- Motion 0.4 按画布像素记录局部 sway，根部固定、发梢边缘加权、有限外扩采样支持；从运动权重中减去保护区及位移保护留量。幅度最多4像素且不超过短边1%，周期2–120秒、相位0–2π弧度。Web shader 消费这些资源，支持关闭/零强度和减少动态；原始RGB保留。
- Validator 校验权重重新推导、保护区零权重、配置与Manifest绑定，以及人物解析来源、标签尺寸/类别和资源哈希。浏览器分开检查粒子与sway，防止一种效果掩盖另一种效果失败。
- 原生接入合并depth/hair/cloth/protected shader，避免后置形变绕过保护；同套画布像素参数，使用引擎g_Time，发梢/衣料分别绑定开关和0–100强度。粒子遮挡层使用相同shader，结构校验覆盖纹理、脚本、参数、shader哈希及保护权重；拒绝同时叠加other/Foliage。引擎时间起点不同，不宣称与Web逐帧相同。
- 保守保护补充：只填充人物轮廓内部4连通背景空洞，纳入person粒子遮挡及protected；原始模型标签不变，策略与像素数记录在区域来源。边缘连通背景保持原状，不冒充Alpha Matting或五官识别。

默认模型：[FASHN Human Parser 官方模型卡](https://huggingface.co/fashn-ai/fashn-human-parser)，18类 SegFormer-B4，输入384×576。采用发布的本地 HF processor 配置；官方说明其 PIL LANCZOS 与训练包 cv2.INTER_AREA 有差异，记录此限制，不宣称训练预处理完全一致。它是语义分割，不是细发丝 Alpha Matting。

## 原生生成

wallpaper_engine.py 从显式安装路径、环境 STATIC2LIVE_WE_PATH、Steam 注册表/库目录或常用目录定位本机，引擎及 resourcecompiler64.exe 必须存在。默认模板来自安装内 assets/effects/depthparallax/preview，读取合法 project/scene；可显式提供同结构合法模板。只复制新目录，不改安装或源模板；拒绝越界资源及符号链接/联接。软件包不包含引擎资源。

从已验证 Motion 0.2 与配置规划 native-plan 0.3；不重复图像分析。Scene 转正画布、关闭相机整体平移/镜头抖动。使用项目自有的 bounded-uv-v1 原生效果：将鼠标规范到 [-1,1]，按深度权重进行局部 UV 位移，scale.x/y=amplitude_px/对应画布边。传输深度=0.2+0.8*规范深度，保持白近语义；最大单轴位移受 amplitude_px 限制，UV 取样钳制到边缘。旧版官方效果 sens=0、center=1 实测只剩整体平移，已停止沿用该映射。项目自有 Shader 随包提供，但仍须在引擎中实际编译和观察，不能以公式或资源编译器返回码代替视觉验收。

真实调用已安装编译器 -tex -i PNG -o TEX，不自己编造纹理。复制完整材质/着色器依赖，记录模板文件哈希、引擎版本、编译器哈希与日志。模型、材质、effect/pass ID、纹理路径和用户属性校验。保留规范 RGB，不生成式重画；同源人物像素覆盖板只遮粒子，同样应用深度效果，不补齐人物背后。

全画布雨/雪/尘/雾用引擎 boxrandom 发射器、有限 maxcount、速度、寿命、颜色、透明度、淡入淡出；随机序列由原生引擎管理。局部粒子、Glow、Cloud Drift 不映射，明确 warning/unsupported，Web 保留完整效果。混合人物排除语义存在差异，明确 warning。

原生dust使用独立translucent材质，sprite直径按size_px×10映射，透明度min(1,intensity×2.4)，Y速度为speed_px_s的0.6–1倍，淡出阈值0.8；这是经本机可见性修正后的近似，不声称与Web像素等效。工程标题包含输出版本号以避免同名旧工程混淆。实际验收须在目标显示比例辨认时间移动和关闭对照。

Foliage Sway 的渲染蒙版由已确认 other 区域外扩 `ceil(amplitude_px)+2` 画布像素，再做1像素 Gaussian 柔边。原始用户蒙版不变；这为逆向采样提供轮廓向外运动所需的有限支撑域，不是背景重建或自动识别。策略记录到 native-plan，Validator 核对生成蒙版与原始区域及幅度一致。

Foliage Sway 默认关闭，仅 --native-sway + 已确认的 other 蒙版；缺失拒绝。使用安装内官方 UV 摇摆效果、编译蒙版与噪声；按官方四项正弦及 strength平方公式约束幅度，不自动识别发梢/植物。最大4像素且≤短边1%。人物覆盖板与基图用一致效果，避免不同运动割裂。

用户属性通过原生 bool 绑定与 property-bound SceneScript 映射强度：视差、粒子、可选摇摆开关与0–100%。SceneScript 根据官方2.8类型和 applyUserProperties 的增量事件处理，范围钳制。native-plan 记录语义差异与外部内置 shader 依赖。

## 降级与验证

引擎/编译器/模板不存在→actual:web、warning、原生not_tested，不假称 Scene 成功。模板非法、引用越界、编译失败→失败并保留诊断，不静默掩盖。

validate 分结构、Web浏览器/视觉、native_runtime；浏览器通过不能代替原生。preview-native 只通过官方 CLI 打开独立命名窗口，不替换桌面；其返回码不证明渲染通过。record-native 要求结构有效与实际检查项目齐全、观察说明，绑定 Manifest 哈希；不会自动创造浏览器通过。未可访问窗口仍 not_tested。

## 使用

```powershell
static2live annotate --input IMAGE --regions VERSION/assets/regions.json --output annotations
```

直接打开新版本index.html。Brush绘制当前类别，Erase只擦当前类别，Protect直接写入protected，Animate绘制当前运动源（头发、衣料等），不是即时播放或效果类型配置。绿色为当前源、红色为保护区、黄色为未确认规则候选；透明不处理。重新生成时protected抑制局部摇摆，具体留量仍由V0.4算法计算。不会自动把face等类别改写成protected，需明确选用保护工具。

支持撤销/重做（按钮及Ctrl/Cmd+Z、Shift+Z、Ctrl+Y）、适应宽度/100/200/400%缩放与滚动。半径单位为规范画布像素，不随CSS缩放改变。撤销最多20步且像素历史不超过64MiB；高分辨率可能不足一步。成功导入清空历史。保存由浏览器下载独立regions.json，不自动覆盖文件，关闭前须手动导出。

可导入已有人工/规则/模型源蒙版。图片哈希、画布、来源、确认和灰度格式必须匹配；错误导入不部分应用。hair_sway/cloth_sway为派生权重，仅忽略并提示，不提供绘制类别，生成时重新推导。CLI --regions 可加载磁盘资源并嵌入；页面导入需独立嵌入PNG的JSON，不能直接读取外部相对路径。

显式清空也导出空蒙版，避免Smart重新采用旧预测；空hair或空protected可能导致启用摇摆的生成拒绝，这是安全检查，不能静默取消保护或使用假区域。修改模型区域保留来源历史，不重画RGB，不联网、不下载模型。
